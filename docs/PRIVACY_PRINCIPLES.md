# Privacy Principles

Privacy and discretion are core product requirements.

## Minimize data

Collect only data necessary for the current product function.

Avoid unnecessary inference or storage of sensitive sexual-wellness preferences.

## Exposure control

Do not expose sensitive behavior unnecessarily in:
- URLs,
- analytics events,
- logs,
- metadata,
- browser titles,
- notifications,
- account dashboards.

## Analytics

Prefer aggregate, minimal and purpose-bound analytics.

Avoid tracking that creates a detailed sensitive-interest profile unless there is a clearly justified, consented product need.

## UX

Explain privacy, delivery discretion and data handling in plain language.
